CodeAlpha Task 4 - Music Player using JavaScript

About the Project

This project is a responsive music player created using HTML, CSS, and JavaScript as part of the CodeAlpha Frontend Development Internship.

Features

- Play and pause music
- Next and previous song controls
- Display song title and artist
- Music progress bar
- Current time and duration
- Volume control
- Responsive design
- Automatic playback of the next song

Technologies Used

- HTML5
- CSS3
- JavaScript

Project Files

- "index.html" - Music player structure
- "style.css" - Styling and responsive layout
- "script.js" - Music player functionality

How to Run

1. Download or clone this repository.
2. Open "index.html" in a web browser.
3. Connect to the internet to load the sample audio tracks.
4. Press the Play button to start listening.
